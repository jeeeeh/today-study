# 오늘공부 (5~7살 한글·영어·수학 카드 앱)

솔정마을과 같은 앱인데, 이름과 사진을 직접 정할 수 있는 버전이에요. 친구네 태블릿에 그대로 설치해서 쓸 수 있어요.

## 처음 켜면
1. "누가 공부할까요?" 화면에서 아이 이름을 적고, 사진(선택)과 색을 고른 뒤 **추가하기**
2. 아이가 더 있으면 같은 방법으로 추가 (최대 4명)
3. **시작하기**를 누르면 아이를 고르는 화면이 나와요

나중에 이름·사진을 바꾸거나 아이를 추가·삭제하려면 처음 화면 오른쪽 위 ⚙️ 부모 메뉴(비밀번호 4자리)에서 할 수 있어요.

## 들어 있는 것
- 한글 · 영어 · 수학, 카드 누르기만 (쓰기 없음), 과목마다 하루 한 번
- 1~10단계: 5번 연속 80% 이상 맞히면 한 단계 위로, 한 판에서 많이 틀리면 바로 한 단계 아래로
- 별 5개마다 알 → 마을 친구, 친구 3명을 합치면 큰 친구·집·나무·무지개·성
- 부모 메뉴: 이름·사진, 아이 추가·삭제, 오늘 한 번 더 열기, 단계 −/＋, 별 조정, 백업

## APK 만들기 · 친구에게 주기
1. GitHub에 새 **Private** 저장소(예: `today-study`)를 만들고, 이 폴더 안의 파일을 모두 올려요 (`.github` 숨김 폴더 포함).
2. Actions 탭에서 "APK 만들기"가 초록 ✓가 되면 Releases 에 `today-study.apk` 가 생겨요.
3. 그 APK 파일을 친구에게 카카오톡 등으로 보내면, 친구 태블릿에서 열어 설치할 수 있어요.
   ("출처를 알 수 없는 앱" 허용과 "Play 프로텍트 → 무시하고 설치"가 필요해요)

## 목소리
태블릿 설정 → 텍스트 음성 변환 → 기본 엔진을 **Google** 로, 한국어 음성은 여성 목소리로 골라 주세요.
